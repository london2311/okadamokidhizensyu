# 全集検索

岡田茂吉全集（講話篇・著述篇・詩歌篇）を横断検索し、必要な項だけをコピーして取り出すための1枚もののページです。サーバーは不要で、GitHub Pages に置くだけで動きます。

- 収録：25巻 8,717項（本文なしの見出しのみが442項ふくまれます）
- 本文の総量：約734万字

## ファイル構成

```
index.html          検索ページ本体（これ1つで完結）
data/manifest.json  巻の一覧
data/*.txt          本文データ（UTF-8）
```

## 設置手順

1. GitHubで新しいリポジトリを作る（Public）
2. このフォルダの中身をそのままアップロードする
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開く

`git` を使う場合：

```bash
git init
git add .
git commit -m "全集検索"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

## 使い方

- 上の棚から巻を選ぶ（初期状態は全巻。押すと外れる）
- ことばを入れて検索。スペースで区切ると、すべてを含む項だけが残る
- 「全文を開く」でその項の全体を読む
- 「この項をコピー」で見出し・出典・本文をまとめて取得。Claudeの会話にそのまま貼れる

選んだ巻の本文を、検索のたびにブラウザが読み込みます。全巻だと初回は少し待ちますが、二度目からはブラウザのキャッシュが効きます。急ぐときは巻を絞ってください。

ルビ（《》の中）は検索対象から外しているので、`節々に浄化` のように地の文どおりに入力すれば当たります。

## データを差し替えるとき

`data/` の .txt を上書きするだけで反映されます。ページ側の書き換えは不要です。文字コードは UTF-8、改行は LF にしてください。

巻を増減した場合だけ `data/manifest.json` を編集します。`count` は棚に表示される項数なので、おおよそで構いません。

```json
{ "slug": "kowa13", "label": "講話13", "group": "講話篇", "count": 300, "kb": 1300 }
```

`slug` がファイル名（`data/kowa13.txt`）に対応します。

## データの形式

各項は次の形で区切られています。この形を保っていれば解析されます。

```
─────────────────────
■■見出し■■
─────────────────────
出典行
─────────────────────
本文
```

## 項目で読む（koumoku.html）

全集の各項を、通信カレッジ（神慈秀明会会員の編集による明主様・岡田茂吉師御論文集、旧geocities）の目次立てにそって、浄霊編・信仰編・経綸編・その他の4編、39章、278項目に振り分けて読むページです。`index.html` の見出しの下からも開けます。

- 各項目には、通信カレッジ目次の細目（約1,500）を割り当てています。細目名と全集の見出しが一致した項は「目次対応」として先頭に並びます
- そのほかの項は、キーワードの出方で「主に説かれた項」と「ふれている項」に分けています
- 目次にない分野（病名の補足、農と食糧、社会と人生、詩歌の形式など）は「補」の印をつけて加えています
- 1つの項が複数の項目に入ります

### ファイル

```
koumoku.html               項目で読むページ
data/topics/index.json     編・章・項目の一覧
data/topics/recs.json      各項の見出し・出典と、どの項目に入っているか
data/topics/c-*.json       章ごとの項の並びと抜粋
tools/taxonomy.json        編・章・項目、キーワード、目次細目の定義
tools/build_topics.py      data/topics を作り直すスクリプト
```

以前の版の `data/topics/g-*.json` は使われなくなったので、削除して構いません。

### 項目を直すとき

`tools/taxonomy.json` の各項目は `id`・`name`・`pat`（キーワードの正規表現、`|` 区切り。`A&&B` と書くとAを数えBも出てくる項に絞る）・`leaves`（通信カレッジ目次の細目名）でできています。直したあと、リポジトリの一番上で

```bash
python3 tools/build_topics.py
```

を実行すると `data/topics/` が作り直されます。
